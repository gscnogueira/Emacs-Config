# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Rules

- This is an Emacs configuration directory. Emacs is self-documenting — packages include extensive docstrings and `describe-*` commands. Consult package documentation before inferring behavior. You have access to all installed package sources under `elpa/`.
- Do not make code changes unless explicitly asked.
- After any changes, ask whether to commit. If yes, propose the commit message and wait for approval before committing (may push along with the commit).

## About

Personal Emacs 30.2 configuration. All configuration lives in `init.el` as a sequence of `use-package` blocks. `custom.el` is auto-generated by Emacs' Custom system — do not edit by hand.

## Applying changes

There is no build step. Changes take effect by reloading the config inside Emacs:

```
M-x load-file RET ~/.emacs.d/init.el RET
```

Or restart Emacs. Packages marked `:ensure t` are installed automatically from MELPA on first load.

## Local overrides

`local.el` (gitignored) is loaded after bootstrap if it exists. Use it for machine-specific settings. The variable `my/ollama-host` defaults to `localhost:11434` but can be overridden there (e.g. a remote GPU machine).

## External dependencies

- **Fonts**: JetBrains Mono (monospace), Literata (variable-pitch for org-mode)
- **nerd-icons**: run `M-x nerd-icons-install-fonts` after first install
- **Node.js**: required for Copilot (`~/.npm-global/bin/copilot-language-server`) and `claude-agent-acp` (`npm install -g @agentclientprotocol/claude-agent-acp`)
- **pyright** and **ruff**: Python LSP and formatter (must be on PATH)
- **hunspell**: spell-checking in LaTeX/org

## Architecture

All configuration is in `init.el` using `use-package`. The loading order matters: `evil` must load before `evil-collection`; LSP packages after `lsp-mode`.

Key package groups:

| Group | Packages |
|---|---|
| Completion stack | vertico, orderless, consult, marginalia, embark, corfu |
| Vim emulation | evil, evil-collection |
| LLM / AI | copilot, gptel, agent-shell |
| Org / notes | org, org-superstar, denote, org-roam |
| LSP / Python | lsp-mode, lsp-pyright, reformatter (ruff), pyvenv |
| LaTeX | auctex, pdf-tools |
| Git | magit, diff-hl |
| Dev tools | haskell-mode, docker-compose-mode, dockerfile-mode |
| Finance | ledger-mode |

**agent-shell** integrates Claude Code via the ACP protocol with `agent-shell-preferred-agent-config 'claude-code`. Context sources: files, region, error.

**gptel** is configured with two backends: GitHub Copilot (default, `gpt-4o`) and Ollama at `my/ollama-host` (models: `gemma4:26b`, `qwen3-coder:30b`).

**org-agenda** reads from `~/org/chatfiocruz/` and `~/org/`. There are no capture templates defined in init.el (add them in `local.el` if needed).

**org-roam** stores research notes at `~/research/` with DB autosync enabled.

**denote** stores notes at `~/notes/`.

**ruff** is configured as an on-save formatter for `python-mode` (line length 88). LSP lint rules: `E`, `F`, `I`, `B`.

## Custom functions

- `my/org-new-fiocruz-sprint` — interactive; prompts for sprint start/end dates, creates a structured `.org` sprint file under `~/org/chatfiocruz/`.
